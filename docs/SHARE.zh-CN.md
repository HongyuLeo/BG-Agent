## 社区介绍

**开源自荐：一起训练自己的酒馆战棋 AI，先把练习场和训练过程公开**

我把自己开发、由 AI 编程工具协助构建的 BG-Agent 整理开源了。它基于 AutoTavern / TavernGym 的模拟器，增加了面向 37.0 的规则适配，以及独立的实体 Transformer + GRU + PPO 训练工程。感谢上游作者开放模拟器与基准。

目前可以在 Linux / WSL 从零初始化模型，运行完整八人对局训练、暂停、续训和导出；提供中英双语指南、版本说明及验证记录。发布准备中完成了 CPU 两局训练、暂停后续训一局和导出检查，这只证明管线跑通，不代表棋力。

受算力成本和训练进度限制，我还没有经过验证的强模型可以分享，也不借用 AutoTavern 论文的15000分作为自己的成绩。多人独立权重合并尚未实现；现在可以共同贡献规则修复、独立实验、统一评测和有授权的高手示范数据。

我希望感兴趣的朋友参与，让更多人能理解和改进游戏AI。技术应当平权，先从能检查、能复现、能贡献的代码开始。

源码与训练指南：https://github.com/HongyuLeo/BG-Agent

1. **0–10秒：问题。**“模拟器开源以后，普通人怎样开始训练自己的酒馆战棋AI？”

3. **25–40秒：证据。**展示真实短测记录、完整局数、更新数、暂停续训和导出。历史记录须标注历史；不要把报告画面称为新录制实训。
4. **40–50秒：现状。**没有强模型、没有多人权重自动合并，完整线上热修等价仍未证明。
5. **50–60秒：邀请。**有CPU可以做短测，有经验可以做评测或规则复现，有合法高手数据可以讨论BC实验。展示仓库地址与贡献入口。
