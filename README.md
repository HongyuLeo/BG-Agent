# BG-Agent · 酒馆战棋 AI 研究工程

[English](README.en.md) · [训练指南](training/README.zh-CN.md) · [规则版本](docs/RULES_VERSION.zh-CN.md) · [AutoTavern 研究与优化方向](docs/AUTOTAVERN.zh-CN.md)

让更多人能够研究、训练和改进游戏 AI。**技术应当平权。**

BG-Agent 提供可检查的酒馆战棋规则适配、结构化策略网络、完整对局 PPO 训练、评估与恢复代码，以及独立的 Windows 桌面和实战研究工具源码。规则后端基于 [AutoTavern / TavernGym](https://github.com/MCG-NJU/AutoTavern) 发展，保留上游许可和贡献归属；这不是 TavernAgent 的官方训练代码。

## 当前版本与持续更新

这是本项目截至 **2026-11-03 的最新整理发布快照**。本项目会持续跟进酒馆战棋规则变化、修复问题并更新版本记录。当前适配目标为 **37.0.0.255130**，采用 2026-11-01 的 Maxwell 卡池修复候选；独立实战工具有 **255790** 客户端适配记录。AutoTavern 当前公开模拟器面向 **36.6.3.253932**。

**“项目最新快照”不等于已经证明与最新线上服务器的全部热修、概率和交互完全一致。** 本项目在 37.0 目标上增加了规则覆盖和修复，但仍保留明确的工作假设与未证明项。具体来源、覆盖、37.0.1 热修核对和更新流程见[规则版本说明](docs/RULES_VERSION.zh-CN.md)。更新不会通过给旧模型改版本标签实现兼容。

## 当前能做什么

| 部分 | 状态 |
|---|---|
| Linux / WSL 从零训练 | 提供源码、构建与短训练入口；CPU 实测见 [training/VALIDATION.json](training/VALIDATION.json) |
| 策略网络 | 实体 Transformer、每座位 GRU、合法动作掩码、名次价值与 PPO |
| 暂停 / 续训 / 导出 | 本地固定规则与模型契约下支持；跨平台和旧安装迁移不承诺自动兼容 |
| 对手与评估 | 脚本、随机、兼容历史模型；独立完整对局统计 |
| Windows 桌面与实战工具 | 发布最新源码，需本机环境适配与手动验收；不是开箱即用的线上自动操作发行版 |
| 强力模型 / 天梯成绩 | **没有经过独立棋力验证的强模型可开源；不宣称 6000 / 15000 分或前 100** |
| 多人权重合并 / 联邦学习 | **尚未实现** |

## 开始训练

建议从 Linux 或 Windows 的 WSL 开始。准备 Python 3.12、PyTorch 2.8.0 和构建工具，再按 [中文训练指南](training/README.zh-CN.md) 安装依赖、编译规则、从零训练。默认使用 CPU 和 `micro` 测试模型，只训练少量完整对局；正式研究可选择更大的档位和 CUDA，但要先测量自己的吞吐与费用。

没有随仓库分发任何预训练权重。初始化模型在本机生成。短测是管线检查，不能用损失下降、局数或自博弈全桌平均 4.5 名证明棋力提高。

## 算力限制与社区愿景

由于算力成本以及尚未完成充分的训练和独立评估，我目前无法提供一个经过验证的强力公开模型。开源环境、训练代码与研究过程，是让更多人参与的第一步。

我希望朋友们联合起来贡献力量：有算力的朋友可以训练独立候选、运行统一评测；有经验的玩家可以贡献经许可、经过匿名化的高手决策和解释；开发者可以改进规则、训练效率、数据质量和可复现工具。

**当前不能把许多人各自训练的 `.pt` 文件直接合并成一个更强的模型。** 同机多个采样进程也不是跨机器联合训练。现在可以分享实验与评测结果、比较候选、把兼容模型加入历史对手池；共享策略版本的远程采样、集中学习器和跨机训练协议属于后续研发。详见[贡献指南](CONTRIBUTING.md)。欢迎共同建设，而不是承诺尚未实现的算力聚合。

