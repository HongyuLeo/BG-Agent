PublicRaces.cs is a narrowed implementation, not an unchanged upstream copy:
- Only required class/field traversal, no card/entity-map dumps or private values.
- Fixed original PE export search: iterate NumberOfNames, resolve ordinal -> function.
- Exact x64 root-domain MOV RIP-relative + RET signature, bounds and read budgets.
- Bounded domain/class/base chains and field/array/list counts; reject cycles/nulls.
- Scope of process access is PROCESS_VM_READ | PROCESS_QUERY_INFORMATION (0x410).
- No WriteProcessMemory, injection, thread creation, function invocation, or UI input.
- Dispose through using on every post-attach failure path.
- V2 corrects original instance_size144 to28 using installed Mono export machine code,
  separately checks array element_size144, and pins the exact Mono DLL SHA.
- Other inherited Unity Mono offsets retain version-risk and need user real-client acceptance.

Exact public connection binding added after offline IL audit:
Network.GotoGameServer(GameServerInfo,bool) first stores m_state.LastGameServerInfo;
its logged game/client values come from that GameServerInfo's GameHandle/ClientHandle.
Network is found only by exact service-class identity in
ServiceManager.s_runtimeServices.m_services (or dynamic locator when runtime is null).
The dictionary walk reads only service wrapper pointers and object class headers;
it does not inspect service business data. Network.m_state is a VALUE TYPE:
Mono struct field offsets include the 16-byte object header, subtracted for embedding.
Read only LastGameServerInfo.<GameHandle>/<ClientHandle> backing fields, not
SpectatorPassword, credentials, address strings, cards, entity maps or seed.
Before/after handle+instance consistency is mandatory. CreateGamePhase must be
CREATED=2 (actual pinned public enum INVALID=0, CREATING=1, CREATED=2).
Network handles must then exactly match the current log connection in the Python bridge;
the helper alone does not open logs, and pointers/Uuid alone do not prove log binding.
